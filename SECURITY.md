# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities to Red Hat Product Security:

- Email: [secalert@redhat.com](mailto:secalert@redhat.com)
- Web: [https://access.redhat.com/security/team/contact](https://access.redhat.com/security/team/contact)

Do not open a public GitHub issue for security vulnerabilities.

For more information about Red Hat's security response process, see:

- [https://access.redhat.com/security/team/contact](https://access.redhat.com/security/team/contact)
